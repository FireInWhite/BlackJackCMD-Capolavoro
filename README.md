# ♠️ BlackJack.cpp

A simple terminal-based **Blackjack game** developed in **C++**.  
Play against the dealer directly from the command line with classic casino mechanics.

---

## 🛠️ Built With

- **C++**

## 🚀 How to Run

### Compile

```bash
g++ main.cpp -o blackjack
```

### Start the game

```bash
./blackjack
```

Windows CMD:

```bash
blackjack.exe
```

---

## 📂 Project Goal

This project was created to practice:

- Object-oriented programming
- Game logic
- Random generation
- Terminal UI design
- C++ fundamentals
